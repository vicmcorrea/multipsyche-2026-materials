\talknote{01:35--02:35, 60 seconds}{
  \begin{itemize}
    \item The corpus covers four Brazilian workplace survey cohorts from 2023 to 2025. There are 44,118 response pairs from 14,706 survey-specific records.
    \item These records describe participation within each survey. A person answering across years cannot be linked across cohorts.
    \item Every retained record has three answers, one per prompt family. One third of the pairs therefore come from mental-health or well-being prompts, whose wording varies by cohort.
    \item The chart shows the cohort sizes. The analysis retained short and repeated answers because they are part of the operational setting.
  \end{itemize}

  \begin{itemize}

    \item Qwen3-Embedding-4B tests paired-text recovery. The 8B version provides a model-scale sensitivity check.
    \item COMETKiwi DA-XL estimates quality from the Portuguese source and English translation, without a human reference translation.

  \source{Camera-ready article, retrieval definition and Table 2. Percentages are overall duplicate-aware R@1.}
\end{tikzpicture}
\talknote{03:40--04:45, 65 seconds}{
  \begin{itemize}
    \item A query asks the encoder to find its counterpart among all 44,118 texts in the other language. Queries receive a retrieval instruction, while candidates are encoded without one.
    \item Rank-one recovery counts a match when the first candidate is the paired target or any candidate with exactly the same normalized target text.
    \item Semantically similar answers with different normalized wording remain competing candidates. This is a demanding corpus-level identification task.
    \item The overall rates are 71.80 percent for English queries and 73.37 percent for Portuguese queries. The next slide shows what this average conceals.
  \end{itemize}
  Source: camera-ready article, Instruction-Conditioned Paired-Text Retrieval and Table 2. Diagram is schematic and contains no response text.
}
